# Minecraft Education Starter

Открой эту папку в редакторе. В `main.ts` регистрируются команды чата, в `greeting.ts` находится приветствие, а в `path.ts` — код постройки дорожки. Каждый новый файл с игровым кодом добавляй в список `files` в `pxt.json`. В MakeCode этот язык называется JavaScript.

## Загрузка в Minecraft Education

1. Создай пустой публичный репозиторий на GitHub и отправь туда эти файлы. Они должны лежать в корне репозитория.

   ```bash
   git add README.md main.ts greeting.ts path.ts agent-path.ts city-layout.ts city.ts pxt.json makecode.d.ts tsconfig.json
   git commit -m "Start Minecraft Education project"
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
   ```

   Замени `USERNAME/REPO` на имя своего аккаунта и репозитория.

2. Открой мир в Minecraft Education, нажми `C` и создай проект в MakeCode.
3. Открой **Extensions**, вставь адрес репозитория GitHub в поиск и выбери расширение.
4. Переключись на **JavaScript** и вставь эту строку в редактор:

   ```typescript
   educationStarter.registerCommands()
   ```

5. Нажми **Play** в MakeCode и введи `hello` в игровом чате. В чате появится приветствие.

## Дорожка с подсветкой

Встань на ровной площадке, повернись в сторону будущей дорожки и введи `path 12` в игровом чате. Постройка начинается в одном блоке впереди. Дорожка состоит из полированного андезита, а справа от каждого четвёртого блока стоит светокамень. Стой на месте, пока дорожка строится. Можно указать длину от 1 до 32 блоков.

Если расширение уже было подключено, после отправки изменений на GitHub удали его из проекта MakeCode и добавь заново, чтобы загрузить новую версию.

## Дорожка руками Агента

На ровной открытой площадке повернись в сторону будущей дорожки, нажми **Play** в MakeCode и введи `agentpath 5` в игровом чате. Агент появится на блок выше твоих ног, пройдёт вперёд и на каждом шаге положит под себя блок. Дорожка будет лежать поверх земли, а каждый четвёртый блок будет из светокамня. Код находится в `agent-path.ts`.

Агент сначала ищет андезит и светокамень в инвентаре. Если нужных блоков хватает, он берёт их из текущей стопки. Если блоков мало, он пополняет эту же стопку. Свободный слот нужен только для материала, которого ещё нет. Если свободных слотов не хватает, Агент использует слоты 27 и 26 в качестве резерва. Он сохраняет выбранные стопки материалов и сообщает в чате номер каждого занятого резервного слота, содержимое которого заменяет.

## Город руками Агента

После обновления расширения нажми **Play** и введи `city 5` в игровом чате. Команда принимает от 1 до 16 домов. `city 4` строит два ряда по два дома, `city 10` — ряды по 4, 4 и 2 дома, `city 12` — три ряда по четыре дома. У каждого дома есть окна, вход со стороны улицы, садик и фонарь. Высота стен чередуется от трёх до пяти блоков.

Город начинается в трёх блоках к востоку и трёх блоках к югу от игрока. Для `city 12` нужна ровная открытая площадка 40 × 30 блоков в этом направлении. Агент кладёт каждый блок сам и сообщает в чате, когда улицы и город готовы. При остановке он показывает смещение от начала города.

В `city-layout.ts` можно изменить расположение клумб, фонарей и окон. `city.ts` строит квартал по этому плану и расходует найденные стопки, пополняя те же слоты по мере необходимости. Если свободных слотов недостаточно, Агент использует слоты с конца инвентаря и сообщает в чате каждый слот, содержимое которого заменит.
